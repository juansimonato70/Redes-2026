Clase 3 — IPv6 y DHCP

💻 Cisco Packet Tracer
Objetivo: Configurar direccionamiento IPv6 (manual y por SLAAC) y un servidor DHCPv4 que asigne direcciones automáticamente a los clientes, comparando ambos mundos de direccionamiento en una misma topología.

1. Materiales necesarios

  • Cisco Packet Tracer (versión 8.x o superior)
  • 3 PC de escritorio (PC-PT), configurados como DHCP
  • 1 Laptop (Laptop-PT), configurada con IPv6 manual
  • 1 Switch (2960)
  • 1 Router con soporte IPv6 (1841 o ISR genérico)
  • 1 Servidor (Server-PT), configurado como servidor DHCP
  • Cables rectos (Copper Straight-Through)

2. Topología a construir

  • PC0, PC1, PC2 y Laptop0 conectados al Switch0
  • Server0 conectado también al Switch0
  • Switch0 conectado al Router0 (interfaz Fa0/0)

3. Guía paso a paso

1
Armar la topología

Colocá los dispositivos y conectalos según el punto 2 con cable recto.

2
Configurar el Router0 con IPv6

En Router0 → CLI, asigná una dirección IPv6 a la interfaz Fa0/0 y activá el ruteo IPv6:

enable
configure terminal
ipv6 unicast-routing
interface FastEthernet0/0
ipv6 address 2001:db8:acad:1::1/64
ipv6 enable
no shutdown

3
Configurar IPv6 manual en la Laptop0

En Laptop0 → Desktop → IP Configuration, seleccioná IPv6 y asigná manualmente una dirección dentro del mismo prefijo que el router (por ejemplo 2001:db8:acad:1::10/64), con el Gateway apuntando a la IP del router.

4
Verificar SLAAC (opcional/comparación)

En Laptop0, cambiá la opción a "IPv6 Automatic (DHCP)" o SLAAC según lo que permita el dispositivo, y observá cómo se autogenera una dirección a partir del prefijo anunciado por el router. Anotá la dirección resultante para compararla con la manual del paso anterior.

5
Configurar el Server0 como servidor DHCPv4

En Server0 → Desktop → IP Configuration, asigná una IP fija (ej: 192.168.1.10/24, Gateway 192.168.1.1). Luego andá a Services → DHCP y configurá: Default Gateway 192.168.1.1, DNS Server 8.8.8.8, Start IP Address 192.168.1.100, Máscara 255.255.255.0. Activá el servicio (On).

6
Configurar la interfaz del Router0 hacia la LAN IPv4

Agregá una segunda dirección IPv4 a la interfaz Fa0/0 (o usá una subinterfaz) para que actúe como Gateway de la red DHCP: ip address 192.168.1.1 255.255.255.0.

7
Configurar PC0, PC1 y PC2 como clientes DHCP

En cada PC → Desktop → IP Configuration, seleccioná "DHCP" en vez de "Static". Esperá unos segundos y verificá que reciban automáticamente IP, máscara, gateway y DNS desde el Server0.

8
Verificar el proceso DORA

Cambiá a modo Simulation, poné un PC en modo Static momentáneamente y volvé a DHCP para regenerar la solicitud. Con "Capture/Forward" identificá los 4 mensajes del proceso DORA (Discover, Offer, Request, Ack) viajando entre el PC y el servidor.

4. Checklist de verificación final

0 / 7 pasos completados

5. Preguntas de reflexión

1. ¿Qué diferencia notaste entre la dirección IPv6 que configuraste manualmente y la que se generó por SLAAC?
2. ¿Qué pasaría si el Server0 se apagara mientras un PC está en modo DHCP? ¿Cómo lo comprobarías en Packet Tracer?
3. ¿Por qué IPv6 puede prescindir de DHCP para direccionar hosts (usando SLAAC), mientras que en IPv4 casi siempre se necesita DHCP o configuración manual?
