Pregunta 1
¿Cuántos bits tiene una dirección IPv4?
Una dirección IPv4 tiene 32 bits, organizados en 4 octetos de 8 bits cada uno.
Pregunta 2
¿Cuál es el valor decimal máximo que puede tener un octeto en una dirección IPv4?
Un octeto tiene 8 bits, y el valor máximo representable con 8 bits (11111111) es 255.
Pregunta 3
¿Qué función principal cumple la máscara de subred?
La máscara de subred indica qué parte de la dirección IP identifica la red y qué parte identifica el host dentro de esa red.
Pregunta 4
En una red 192.168.1.0/24, ¿cuál es la dirección de broadcast?
Con máscara /24, los últimos 8 bits son de host. La dirección de broadcast tiene todos los bits de host en 1, es decir 192.168.1.255.
Pregunta 5
¿Qué tipo de entrega de mensaje IPv4 envía datos a un único destino específico?
Unicast es la comunicación uno a uno: un dispositivo origen envía datos a un único dispositivo destino específico.
Pregunta 6
¿Cuál de las siguientes es una dirección IPv4 privada (uso interno, no enrutable en Internet)?
El rango 192.168.0.0 – 192.168.255.255 está reservado para redes privadas (junto con 10.0.0.0/8 y 172.16.0.0/12).
Pregunta 7
¿Cuántas direcciones de host utilizables tiene una subred con máscara /30?
Una /30 tiene 2 bits de host (2²=4 direcciones totales), pero se restan 2 (red y broadcast), quedando 2 direcciones utilizables — ideal para enlaces punto a punto entre routers.
Pregunta 8
¿Por qué siempre se pierden 2 direcciones en cada subred IPv4?
La primera dirección de cada subred (todos los bits de host en 0) identifica la red, y la última (todos los bits de host en 1) es la dirección de broadcast — ninguna de las dos puede asignarse a un host.
Pregunta 9
¿Cuál es la representación binaria del número decimal 192?
192 = 128 + 64 = 2⁷ + 2⁶, lo que en binario es 11000000.
Pregunta 10
¿Qué protocolo de capa de red opera junto a IP y se usa para diagnosticar problemas de red (por ejemplo, el comando ping)?
ICMP (Internet Control Message Protocol) opera en la capa de red junto a IP y es el protocolo detrás de utilidades de diagnóstico como ping y traceroute.
Pregunta 11
Una empresa necesita crear una subred para un enlace WAN entre dos routers, que solo requiere 2 direcciones de host. ¿Qué máscara es la más eficiente?
La máscara /30 ofrece exactamente 2 direcciones de host utilizables, ideal para no desperdiciar direcciones en un enlace punto a punto.
Pregunta 12
¿Qué tipo de dirección IPv4 se usa para enviar el mismo mensaje a todos los dispositivos de una subred simultáneamente?
Broadcast envía un mensaje a todos los dispositivos de la subred a la vez, usando la dirección de broadcast (todos los bits de host en 1).
