Clase 1 — Fundamentos de Redes

Respondé las 12 preguntas y presioná "Corregir cuestionario" al final. Vas a ver tu puntaje y la justificación de cada respuesta correcta.
⚠️ Respondé todas las preguntas antes de corregir.
Pregunta 1
¿Qué tipo de red conecta dispositivos dentro de un área geográfica reducida, como una oficina o un hogar?
La LAN (Red de Área Local) cubre distancias cortas, típicamente un edificio o campus.
Pregunta 2
Una empresa con oficinas en Buenos Aires y Córdoba conecta ambas sedes mediante un enlace del proveedor de internet. ¿Qué tipo de red están utilizando?
La WAN (Red de Área Amplia) conecta LANs distantes entre sí, generalmente a través de un proveedor de servicios.
Pregunta 3
¿Cuál de las siguientes opciones describe correctamente el ancho de banda?
El ancho de banda mide la capacidad de transmisión de un medio, generalmente en bits por segundo (bps).
Pregunta 4
Un navegador web que solicita una página a un servidor web es un ejemplo de:
El cliente es el dispositivo o software que inicia la solicitud de un servicio a un servidor.
Pregunta 5
¿Qué dispositivo se utiliza para conectar múltiples equipos dentro de una misma red local y dirigir el tráfico entre ellos de forma inteligente?
El switch conecta dispositivos dentro de una LAN y aprende direcciones MAC para enviar el tráfico solo al destino correcto.
Pregunta 6
¿Cuál de los siguientes medios de transmisión ofrece mayor inmunidad a interferencias electromagnéticas y permite las mayores distancias?
La fibra óptica transmite luz en lugar de electricidad, por lo que no le afectan las interferencias electromagnéticas y alcanza distancias mucho mayores.
Pregunta 7
¿Qué tipo de conector se utiliza habitualmente en cables de par trenzado (UTP) para redes Ethernet?
El conector RJ45 es el estándar para cableado UTP en redes Ethernet.
Pregunta 8
Un dispositivo que crea una red Wi-Fi y retransmite por radiofrecuencia la conexión que recibe de un router o switch se llama:
El punto de acceso (Access Point) es el dispositivo físico que genera la señal Wi-Fi para los clientes inalámbricos.
Pregunta 9
Un usuario comparte la conexión de datos móviles de su celular para que su notebook navegue por internet. ¿Cómo se llama esta función?
El hotspot (o tethering) permite que un dispositivo móvil comparta su conexión de datos con otros equipos.
Pregunta 10
¿Qué tecnología de corto alcance (pocos centímetros) se utiliza habitualmente para pagos móviles sin contacto?
NFC (Near Field Communication) permite el intercambio de datos entre dispositivos que se encuentran a pocos centímetros de distancia, muy usado en pagos móviles.
Pregunta 11
Al configurar un router doméstico por primera vez, ¿cuál es el primer paso habitual?
Para configurar un router doméstico, primero hay que acceder a su interfaz web de administración usando su dirección IP por defecto (por ejemplo, 192.168.1.1 o 192.168.0.1).
Pregunta 12
¿Qué opción de conectividad al ISP utiliza líneas telefónicas existentes y ofrece velocidades más altas que el dial-up tradicional?
DSL (Línea de Suscriptor Digital) aprovecha el cableado telefónico de cobre existente para brindar acceso a internet de banda ancha.
