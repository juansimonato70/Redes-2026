Clase 7 — ICMP y Herramientas de Diagnóstico

Pregunta 1
¿Qué función cumple principalmente el protocolo ICMP?
ICMP está diseñado para enviar mensajes de control y reportar errores, no para transportar datos de aplicación.
Pregunta 2
¿ICMP hace que el protocolo IP sea confiable?
ICMP no hace confiable a IP: simplemente proporciona información sobre problemas en la red, pero los propios mensajes ICMP pueden perderse igual que cualquier datagrama IP.
Pregunta 3
¿Qué tipo y código ICMP usa el comando ping para la solicitud (request)?
Ping envía un mensaje ICMP Tipo 8 (Echo Request) y espera un Tipo 0 (Echo Reply) como respuesta.
Pregunta 4
¿Qué mecanismo usa traceroute para descubrir cada router en el camino hacia el destino?
Traceroute incrementa el TTL en cada envío; cuando el TTL llega a 0 en un router, este responde con ICMP Time Exceeded (Tipo 11), revelando así cada salto de la ruta.
Pregunta 5
¿Qué mensaje ICMP recibirías si intentás llegar a un host que no responde y el router intermedio determina que no hay ruta hacia él?
Cuando un destino no puede ser alcanzado, el router responde con un mensaje ICMP Tipo 3 (Destination Unreachable), con distintos códigos según la causa específica.
Pregunta 6
¿Qué función adicional cumple ICMPv6 que ICMPv4 no tiene?
ICMPv6 incluye el Neighbor Discovery Protocol (mensajes tipo 133-137), que cumple en IPv6 la función que ARP cumple en IPv4.
Pregunta 7
¿Cuál de los siguientes es un ataque que explota ICMP?
Ping of Death envía paquetes ICMP mal formados o demasiado grandes para intentar provocar fallas en el sistema destino.
Pregunta 8
Si un firewall bloquea completamente ICMP, ¿qué consecuencia práctica tiene esto para el diagnóstico de red?
Bloquear ICMP hace que ping/traceroute parezcan indicar que el host está caído (falso negativo), aunque el servicio real (por ejemplo HTTP) puede estar funcionando perfectamente.
Pregunta 9
¿Qué comando usarías para ver la configuración de red (IP, máscara, gateway, DNS) de tu propia PC en Windows?
ipconfig /all muestra la configuración completa de red en Windows: IP, máscara, gateway, DNS, MAC, estado DHCP, etc.
Pregunta 10
¿Para qué sirve el comando netstat?
netstat muestra las conexiones de red activas, puertos abiertos y estadísticas por protocolo — útil para saber qué aplicaciones están usando la red.
Pregunta 11
Estás diagnosticando "no puedo acceder a www.ejemplo.com". El ping a 8.8.8.8 funciona, pero nslookup no resuelve el nombre. ¿Cuál es el problema más probable?
Si el ping a una IP funciona pero nslookup no resuelve nombres, la conectividad básica está bien pero hay un problema específico de DNS (por ejemplo, servidor DNS mal configurado o caído).
Pregunta 12
¿Qué comando usarías para verificar si un servidor web está escuchando específicamente en el puerto 80?
telnet ejemplo.com 80 intenta conectar específicamente a ese puerto; si conecta, el puerto está abierto y el servicio está escuchando.
